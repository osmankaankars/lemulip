# Contributing

Keep changes focused and run the relevant [development checks](docs/DEVELOPMENT.md). Preserve originals, non-overwriting outputs, process isolation, and cancellation cleanup. Native UI changes need a macOS build and interaction check.

Bug reports should include app/macOS versions, operation, input format, and the error with a synthetic sample. Exclude private paths, logs, and documents. Use [private vulnerability reporting](SECURITY.md) for security findings.

Keep English and Turkish app text consistent. Preserve filenames, format acronyms, API names, and identifiers exactly.
