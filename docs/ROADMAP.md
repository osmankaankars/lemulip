# Roadmap

Lemulip is a free, open-source macOS file utility. The current downloadable
version is [0.1.16](https://github.com/osmankaankars/lemulip/releases/tag/v0.1.16).
See the [User Guide](USER_GUIDE.md) for current controls and
[Formats](FORMATS.md) for supported routes and limits.

## Available Now

- Drag-wheel access from the desktop and Finder, plus a workspace and CLI.
- Image conversion, visual crop, resize, rotation, flip, and metadata removal.
- PDF organization, merge preview, splitting, extraction, rotation, and OCR.
- Audio waveform trimming, video trimming, and video cropping.
- Basic Word and Excel exports, document conversions with optional engines,
  subtitle conversion, and archive tools.
- Three appearances: Orchard Night, Vivid Pistachio, and Lemon Drop.
- Keyboard navigation, manual-wheel accessibility actions, and workspace
  position recovery added in 0.1.16.

## Future Directions

- PDF to editable DOCX and slide-to-image export, with clear layout limits.
- Finder-compatible file references for paste, and improvements to the floating shelf.
- Photo adjustments, metadata editing, canvas/collage tools, and richer media editing.

These are future ideas, not current menu features or promised release dates.
Suggestions and reproducible bug reports are welcome through
[GitHub Issues](https://github.com/osmankaankars/lemulip/issues).

## Product Principles

Keep processing local, preserve originals when creating conversions, make
optional engines explicit, and keep the app lightweight. The website’s sample
workflows are illustrations; use the native app for real file processing.
